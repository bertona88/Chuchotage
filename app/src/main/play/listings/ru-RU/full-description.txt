Chuchotage — персональная утилита речевого перевода для Android. Запустите сеанс, выберите язык, который хотите слышать, и Chuchotage автоматически определит исходный язык, переводя речь в реальном времени.

Используйте собственный ключ API OpenAI или учетные данные в стиле ChatGPT/Codex. Chuchotage хранит учетные данные на устройстве, не содержит рекламы, не использует SDK аналитики и не требует размещенного backend Chuchotage для обычного использования.

Возможности:
- Перевод речи в реальном времени
- Автоматическое определение исходного языка
- Выбор языка вывода в настройках
- Предпочтение микрофона телефона или гарнитуры
- Учетные данные хранятся на устройстве
- Без рекламы и SDK аналитики

Во время активного сеанса аудио микрофона и настройки перевода отправляются напрямую в OpenAI для перевода в реальном времени. При остановке перевода захват микрофона прекращается.

Chuchotage предназначен для личной помощи с переводом в реальном времени и может быть неточным. Важные разговоры следует проверять с квалифицированным устным переводчиком.
