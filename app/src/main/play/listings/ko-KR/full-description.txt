Chuchotage는 Android용 개인 음성 번역 유틸리티입니다. 세션을 시작하고 듣고 싶은 언어를 선택하면 Chuchotage가 원본 언어를 자동으로 감지하면서 음성을 실시간으로 번역합니다.

직접 보유한 OpenAI API 키나 ChatGPT/Codex 방식의 자격 증명을 사용할 수 있습니다. Chuchotage는 자격 증명을 기기에 저장하며 광고, 분석 SDK, 일반 사용을 위한 호스팅 Chuchotage 백엔드가 없습니다.

기능:
- 실시간 음성 번역
- 원본 언어 자동 감지
- 설정에서 선택하는 출력 언어
- 휴대폰 마이크 또는 헤드셋 마이크 선호 설정
- 기기에 저장되는 자격 증명
- 광고 및 분석 SDK 없음

활성 번역 세션 중에는 마이크 오디오와 번역 설정이 실시간 번역을 위해 OpenAI로 직접 전송됩니다. 번역을 중지하면 마이크 캡처도 중지됩니다.

Chuchotage는 개인 실시간 번역 지원 도구이며 완벽하지 않을 수 있습니다. 중요한 대화는 자격을 갖춘 인간 통역사에게 확인해야 합니다.
